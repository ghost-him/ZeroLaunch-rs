# 界面文案国际化规范

所有用户可见文本必须由 `crates/zerolaunch-rs/locales/{zh-Hans,zh-Hant,en}.json` 提供，并通过 `I18nManager::t` 取当前语言文案。

## 允许硬编码

- 日志与调试输出
- 配置 key、组件 id、动作 id、文件路径
- 后端返回的数据内容（由数据源负责其本地化）
- 仅用于测试的字符串

## 工作流

1. 在三份语言文件中增加同名 key。
2. GPUI 视图通过 `state.get_i18n_manager()` 取文案；`SettingsView` 等已有 `tr` 辅助方法的视图直接调用。
3. 托盘、插件 HostModule 与 CLI 同样复用后端 `I18nManager`，不另建语言文件。

```rust
// ✅
let title = self.tr("settings.title");

// ❌
let title = "设置";
```

缺少译文时 key 会原样显示；新增 key 必须三语言同步。
