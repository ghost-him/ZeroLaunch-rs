# ZeroLaunch 冒烟测试手册

> 适用范围：2026-08-05 统一会话重构 + 键盘契约破坏性重构（声明式按键绑定 `bindings`、删除宿主兜底与 `claim_all`、`PanelKeyAction::Confirm` 三分支语义、`confirmQuery` 在途防重）后的运行时验证。
> 前置：`cargo test` / `bun run build` 已通过。本手册验证**运行时行为**（跨 IPC 契约、键盘分发、事件推送），静态测试覆盖不到的部分以此为准。
> 预计耗时：15–20 分钟。

## 0. 前置准备

### 0.1 环境检查（每次测试前）

| 检查项 | 操作 | 通过标准 |
|---|---|---|
| 残留进程 | 任务管理器查 `zerolaunch-rs.exe` | 无（有则结束） |
| 端口占用 | `netstat -ano \| findstr "12345 8143"` | 无监听（vite 12345 / CLI 8143） |
| 构建产物 | 工作区根 `bun run tauri dev` | 无编译错误 |

### 0.2 启动与日志证据

`bun run tauri dev` 后按顺序等待以下日志出现（全部出现 = 启动正常）：

1. Vite dev server 监听 `12345`
2. Cargo 编译完成并启动 `zerolaunch-rs.exe`
3. 配置 / 插件初始化完成（内置组件注册无 error 级日志）
4. 搜索管道构建完成
5. CLI server 监听 `127.0.0.1:8143`
6. UI 窗口 / 托盘初始化
7. **`应用启动完成`**（最终标志）

> ⚠️ 若日志出现 schema 校验警告（`unknown setting` / `minItems` 违规等）→ 旧配置与新版不兼容。**不要删配置**，记录下来报告。

### 0.3 测试辅助约定

- **剪贴板验证**：所有「复制」用例，复制后必须 `Win+V` 或粘贴到记事本确认内容。
- **LLM 调用计数**：翻译相关用例的防重判据依赖日志——dev 控制台搜索 translator 的请求/响应日志（或日志目录）。「仅一次调用」指目标时间段内该请求只出现一次。
- **默认触发词**：translator = `fy` / `tr` / `翻译`；calculator = `=`。如用户配置改过，按配置替换。

## C. 翻译面板 on_enter 模式（本次核心变更 ①）

> 前置：translator 设置为 on_enter 模式。四态面板：`empty`（用法提示）/ `ready`（"按 Enter 翻译"）/ 成功（含「复制译文」动作）/ `error`（失败）。

| ID | 前置 | 操作 | 正确现象 |
|---|---|---|---|
| C1 | — | 输入 `fy hello` | 面板出现，状态 **ready**：「按 Enter 翻译」，**不**自动翻译（无 LLM 调用日志） |
| C2 | C1 | 按 `Enter` | 发起翻译 → 面板显示译文（primary）与「复制译文」动作按钮 |
| C3 | C2（成功） | 按 `Enter` | **剪贴板 = 译文**（Confirm 三分支：有可执行动作 → 执行默认动作复制）。面板不崩溃 |
| C4 | C2（成功） | 按 `Ctrl+Enter` | 剪贴板 = 译文，且**无新翻译请求**（直接复制，不触发翻译） |
| C5 | 任意翻译面板 | 按 `Escape` | 返回默认搜索面板（GoBack），输入框保留可继续输入 |
| C6 | 面板 **error** 态（无凭据/网络失败，如输入 `fy @xx hello` 非法语言） | 按 `Enter` | 重新发起翻译（失败重试语义）；再次失败仍停留 error 态，不崩溃 |
| C7 | — | 输入 `fy`（无内容）或 `fy ` | 面板显示用法提示（empty 态，`用法: fy hello \| fy @en 你好 ...`），**无 LLM 调用** |
| C8 | C7 | 空面板按 `Enter` | 无操作 / 无 LLM 调用（空输入无害） |
| C9 | — | 输入 `fy @en 你好` → `Enter` | 按语言方向翻译（中文 → 英文），成功面板出现 |
| C10 | C2 成功后 | 修改查询为 `fy world` → `Enter` | 新译文替换旧译文；再 `Enter` 复制的是**新**译文（剪贴板不串旧值） |
| C11 | 触发词前缀 | 输入 `fy h`（部分文本）→ `Enter` | 按当前文本翻译（与 C2 同语义，验证不要求完整单词） |
| C12 | — | 输入 `tr hello`（第二触发词） | 同 C1：面板 ready，可 Enter 翻译（触发词均生效） |

## D. 翻译面板 live 模式（本次核心变更 ②：防重）

> 前置：translator 切换为 live 模式（设置 → 翻译 → 模式）。live = 输入防抖自动翻译。

| ID | 前置 | 操作 | 正确现象 |
|---|---|---|---|
| D1 | — | 输入 `fy hello`（不按 Enter） | 防抖（默认若干秒）后**自动**翻译，无需 Enter；成功面板含「复制译文」 |
| D2 | 面板自动翻译**在途**（译文未返回） | 快速按 `Enter` | **不产生第二次翻译请求**——日志中仅一次 LLM 调用（`panelQueryInFlight` 防重生效） |
| D3 | D1 成功 | 按 `Enter` | 剪贴板 = 译文（与 C3 同：有动作 → 复制） |
| D4 | 面板 **error** 态 | 按 `Enter` | 重新发起翻译（重试）；成功则面板恢复 |
| D5 | 任意 live 面板 | 按 `Escape` | 返回默认搜索 |
| D6 | D1 成功后 | 快速连续改输入 `fy he` → `fy hel` → `fy hell` | 防抖合并：仅对最终文本发起一次翻译（日志无多次重复请求） |
| D7 | D1 成功后 | 修改文本 → 自动翻译**在途**时按 `Ctrl+Enter` | 直接复制**当前已有译文**（若此前有），不触发新翻译；若从未成功过则无操作，不崩溃 |

> 触发词 `=`。计算同步完成，无「等待」态。面板形态：行内（保留搜索栏）。

| ID | 前置 | 操作 | 正确现象 |
|---|---|---|---|
| E1 | — | 输入 `= 1+1` | 面板立即显示结果 `2`（整数格式），含「复制结果」动作 |
| E2 | E1 | 按 `Enter` | **剪贴板 = `2`**（Confirm：有动作 → 执行默认动作复制） |
| E3 | — | 输入 `= 1.5*2` | 面板显示 `3`（整数值省略小数位，epsilon 比较） |
| E4 | — | 输入 `= (2+3)*4` | 面板显示 `20`（括号/优先级正确） |
| E5 | — | 输入 `= 1+`（不完整） | 面板显示错误提示（error 态），**无**「复制结果」动作 |
| E6 | E5 | 按 `Enter` | 不崩溃、面板保持（无动作 → 确认查询 = 重新计算，结果仍是错误提示） |
| E7 | — | 输入 `= `（单独） | 提示面板，不崩溃 |
| E8 | 任意计算面板 | 按 `Escape` | 返回默认搜索面板 |
| E9 | E1 成功后 | 修改为 `= 2*10` → `Enter` | 结果更新为 `20`；再 `Enter` 复制的是 `20`（剪贴板不串旧值） |

## F. 插件面板通用契约（声明即接管 / 放行）

> 本组验证键盘契约的**边界语义**——命中声明键 = 宿主接管；未命中 = 放行给输入框，宿主不解释、不兜底、不拦截。

| ID | 前置 | 操作 | 正确现象 |
|---|---|---|---|
| F1 | 任意插件面板（翻译/计算） | 按字母键 `a`、`x` 等 | 字符进入搜索输入框（未声明键放行），输入框光标正常移动 |
| F2 | 任意插件面板 | 按 `Backspace` / `Delete` | 正常编辑输入框内容（放行） |
| F3 | 任意插件面板 | 按 `↑` / `↓` | 无动作且不报错（未声明键放行；若输入框有历史则走浏览器行为） |
| F4 | 翻译面板（C2 成功态） | 按 `Ctrl+C` | 不拦截（放行），无宿主动作 |
| F5 | 翻译面板 → `Esc` 返回搜索 → **再次**输入 `fy hello` 重入面板 | 重入后面板内按 `Enter` | 按键契约仍生效（面板重入后 session-state 重推，bindings 不丢失） |
| F6 | 插件面板 | 连续快速按 `Enter` ×3 | 无重复动作：有动作时只复制一次（防重），无动作时只发起一次查询 |
| F7 | 插件面板与宿主面板切换 | 面板内 `Esc` 返回搜索后，按 `Enter` | 回到**宿主** Enter 语义（启动选中候选），不残留插件按键契约 |
